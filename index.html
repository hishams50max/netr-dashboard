📋 One-time Setup: Publish Your Google Sheet
1
Open your Google Sheet: NETR Dashboard Master Data File
2
Click File → Share → Publish to web
3
In the dialog, select Entire Document and format Comma-separated values (.csv), then click Publish
4
Click ⟳ Refresh above — the dashboard will load live data from your Sheet automatically.
Note: Publishing makes the data readable by this dashboard (read-only). Your editing access remains unchanged. You can unpublish any time from the same menu.
